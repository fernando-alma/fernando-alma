### 🏆 Proyecto Destacado: Plataforma Core para Hackatones (AI Weekend)
Desarrollé de forma **íntegra y autónoma** la infraestructura digital oficial para la gestión de hackatones de **AI Weekend Mendoza**, un sistema multiusuario diseñado desde cero para centralizar el ciclo colaborativo de eventos tecnológicos de alta intensidad.

* **Arquitectura & Backend:** Enfoque de ruteo personalizado y arquitectura bajo el patrón MVC en PHP, exponiendo una API RESTful sólida.
* **Seguridad & Roles:** Módulos avanzados de autenticación, control de accesos basados en roles (Admin, Miembro, Usuario) y middlewares de control de peticiones.
* **Calidad de Software:** Suite completa de pruebas de integración automatizadas con **PHPUnit** y documentación estandarizada de endpoints bajo la especificación **OpenAPI/Swagger**.
* **Impacto Comercial:** Soportó con **éxito absoluto y cero caídas** a 151 usuarios activos registrados, 45 ideas plasmadas y 23 proyectos finales durante tres días de alta demanda concurrente. Actualmente se proyecta como el estándar oficial para los próximos eventos nacionales de la organización.
